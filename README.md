# OPIc 연습

오픽 난이도 5-5 모의고사 5회분(75문항)을 듣고 연습하는 웹페이지입니다.
질문을 눌러 듣고, 2분 동안 직접 답한 뒤 펼쳐서 모범답안과 비교합니다.

## 기능

- 질문 읽어주기 — 브라우저 내장 음성(Web Speech API), 설치나 API 키 없이 동작
- 목소리 선택 — 기기에 설치된 영어 음성 중에서 고를 수 있고, 선택은 기억됩니다
- 답변 듣기 — 모범답안도 같은 방식으로 읽어줍니다
- 내 답변 녹음 — 녹음 후 바로 다시 들어볼 수 있습니다
- 다크 모드 자동 지원, 모바일 대응

## 올리는 법

1. 깃허브에서 새 저장소를 만듭니다. 이름은 `opic-practice` 정도면 됩니다. Public으로 만들어야 무료 호스팅이 됩니다.
2. `Add file` → `Upload files`를 눌러 `index.html`과 이 `README.md`를 끌어다 놓고 `Commit changes`를 누릅니다.
3. 저장소 `Settings` → 왼쪽 메뉴 `Pages`로 들어갑니다.
4. Source를 `Deploy from a branch`로 두고, Branch를 `main` / `/ (root)`로 고른 뒤 `Save`.
5. 1~2분 뒤 `https://아이디.github.io/opic-practice` 주소로 접속됩니다.

## 알아둘 점

**녹음은 GitHub Pages 주소에서만 됩니다.** `index.html` 파일을 컴퓨터에서 직접 열면 브라우저가 마이크를 막습니다. 읽어주기 기능은 파일을 직접 열어도 잘 동작합니다.

**목소리는 기기마다 다릅니다.** 크롬 PC와 안드로이드에서는 구글 음성, 아이폰 사파리에서는 애플 음성이 나옵니다. 상단 드롭다운에서 마음에 드는 것을 고르세요. 크롬에서 `Google US English`가 구글 번역과 같은 목소리입니다.

**목소리를 통일하고 싶다면** 음성 파일을 미리 만들어 넣는 방법이 있습니다.

```bash
pip install edge-tts
edge-tts --voice en-US-JennyNeural --text "질문 내용" --write-media audio/1-2.mp3
```

이렇게 뽑은 mp3를 `audio/` 폴더에 넣고 `speak()` 함수에서 파일을 먼저 찾도록 고치면, 모든 기기에서 같은 목소리가 나옵니다.
