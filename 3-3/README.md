# OPIc 3-3 연습

오픽 자가진단 3-3 모의고사 10회분(150문항)을 듣고 연습하는 웹페이지입니다.
질문을 눌러 듣고, 2분 동안 직접 답한 뒤 펼쳐서 모범답안과 비교합니다.

## 기능

- 질문 읽어주기 (브라우저 내장 음성, 목소리 선택 가능)
- 펼치면 질문 원문과 모범답안이 함께 보임 — `그대로`(교재 문장) / `응용`(패턴 응용) 표시
- 답변 듣기, 내 답변 녹음
- 마지막으로 본 회차와 고른 목소리를 기억

## 올리는 법

이전 연습 사이트와 같습니다. 새 저장소에 `index.html`과 이 파일을 올리고 Settings → Pages에서 `main` / `/ (root)`로 배포하면 됩니다.
녹음은 `https://` 주소에서만 동작합니다 (파일을 직접 열면 브라우저가 마이크를 막음).
